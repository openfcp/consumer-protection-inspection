# 消保检查 Skill（Consumer Protection Inspection）

> 金融机构消保检查全流程作业规范技能 · 作者：八大权益 · 版本：v1.1.0

## 简介

将金融机构消保检查岗位的专业能力转化为可执行的工作流，覆盖消保检查全流程：**检查制度建设 → 六大领域检查执行 → 问题整改督办 → 统计分析与报告**。核心定位是消保工作的"内部督查"与"质量把控者"——验证消保制度机制是否有效执行、工作是否落实到位、风险是否得到控制，形成管理闭环。

## 适用场景

- 制定/修订消保检查制度、检查标准和年度检查计划
- 执行六大领域检查：消保体制建设、机制运行、操作与服务、纠纷化解、金融教育宣传、消费者服务与个人信息保护
- 生成检查方案、检查记录表、访谈提纲、抽样方案
- 撰写检查报告、整改通知、整改跟踪台账
- 检查问题分类统计、覆盖率/整改完成率统计、季度/年度检查工作总结

## 核心方法

- **五维检查思路**：制度健全性 → 流程合规性 → 执行有效性 → 结果成效性 → 整改闭环性
- **检查发现四要素**：问题描述 + 严重程度 + 判定依据（具体条款号）+ 证据索引，缺一不可
- **监管标准基座**：《金融机构消费者权益保护监管评价办法》（金规〔2025〕20号）七项评价要素；金融消费者八项基本权利作为问题定性归口

## 四大角色

| 角色 | 典型任务 |
|------|----------|
| 制度与标准建设者 | "帮我制定消保检查管理办法""更新检查评价标准" |
| 检查执行者 | "帮我检查消保体制建设情况""生成分支机构检查方案" |
| 整改督办者 | "根据检查发现写整改通知""更新整改进度" |
| 统计分析与报告者 | "生成季度检查工作总结""统计整改完成率" |

## 安装使用

将本目录复制到 WorkBuddy 用户级技能目录：

```
~/.workbuddy/skills/consumer-protection-inspection/
```

在对话中直接使用触发词即可，例如"帮我制定消保检查办法""生成检查方案""写一份整改通知"。
