# 消保检查监管依据参考

> 本文件汇总消保检查工作的法规基座与监管评价核心标准。执行任何检查任务前，先对照本文件确认判定依据。

## 一、核心法规清单

| 法规文件 | 文号 | 要点 |
|----------|------|------|
| 《国务院办公厅关于加强金融消费者权益保护工作的指导意见》 | 国办发〔2015〕81号 | 消保工作总体要求，金融消费者八项基本权利（详见第五部分） |
| 《关于银行保险机构加强消费者权益保护工作体制机制建设的指导意见》 | 银保监发〔2019〕38号 | 体制机制建设要求：董事会、高管层、消保部门、审查/考核/审计机制 |
| 《中国人民银行金融消费者权益保护实施办法》 | 中国人民银行令〔2020〕第5号 | 人民银行履职领域消保实施要求 |
| 《银行保险机构消费者权益保护管理办法》 | 银保监会令2022年第9号 | 消保工作全面规范：体制、机制、经营行为、投诉处理、教育宣传 |
| 《金融机构消费者权益保护监管评价办法》 | 金规〔2025〕20号 | 消保监管评价核心标准（2025年9月10日印发施行，详见下文） |
| 《金融机构产品适当性管理办法》 | 国家金融监督管理总局令2025年第7号 | 2025年7月11日公布，2026年2月1日施行；产品风险评级、客户风险评估与适当性匹配、保险分类分级与销售资质分级、特殊群体保护 |

> **版本提示**：金规〔2025〕20号自公布之日起施行，《银行保险机构消费者权益保护监管评价办法》（银保监发〔2021〕24号）同时废止。检查 2025 年 9 月 10 日前的评价年度时，按当时有效的 21 版办法判定（21 版为 5 项基本要素、法人与一级分支机构得分按 60%/40% 加权）；此后一律适用 25 版 7 项要素、50%/50% 加权。因适当性管理办法 2026 年 2 月 1 日才施行，检查 2026 年 2 月 1 日前的业务时，适当性部分应以当时有效的监管规定和机构自定制度为准，不得直接引用该办法条文追责。

## 二、金规〔2025〕20号核心要点（监管评价标准）

### 2.1 七项评价要素及权重（权重之和为100%）

| 评价要素 | 权重 | 对应检查领域 |
|----------|------|--------------|
| 体制机制 | 不低于10% | 消保体制建设 + 消保机制运行 |
| 适当性管理 | 不低于10% | 操作与服务（适当性管理部分） |
| 营销行为管理 | 不低于25% | 操作与服务（营销宣传、信息披露、格式条款、双录、合作机构等） |
| 纠纷化解 | 不低于25% | 纠纷化解检查 |
| 金融教育 | 不低于10% | 金融教育宣传检查 |
| 消费者服务 | 不低于5% | 特殊群体服务 |
| 个人信息保护 | 不低于5% | 个人信息保护检查 |

- 金融监管总局每年可动态调整要素权重及具体评价指标；派出机构可在授权范围内合理调整辖内评价指标。

### 2.2 评价对象与豁免

- 评价对象：境内依法设立、由金融监管总局及其派出机构监管、向消费者提供金融产品和服务的金融机构。
- 明确排除：政策性银行、农村资金互助社、金融资产管理公司、货币经纪公司、金融资产投资公司、保险资产管理公司、养老金管理公司、再保险公司、政策性保险公司、相互保险组织、保险专业中介机构。
- 新设机构豁免：开业不满一个完整会计年度的不作为评价对象（较21版办法的2个会计年度缩短）。
- 农村中小银行（农商行、农合行、农信社、村镇银行）：派出机构可仅对法人机构评价，原则上5年全覆盖。

### 2.3 评价方法与总分计算

1. **指标得分**：针对每一评价要素中的不同评价指标评分。
2. **要素得分**：要素下各评价指标得分之和。
3. **总体得分**：法人评价得分与一级分支机构平均得分按**各50%加权平均**（21版为60%/40%，25版提升分支机构权重，强调执行落地）。
4. **评价结果**：按分级标准以总体得分确定级别档次。

### 2.4 评价结果分级（1-5级，2级和3级分A/B/C三档）

| 级别 | 分数区间 | 含义 |
|------|----------|------|
| 1级 | 90分（含）-100分 | 领先 |
| 2A级 | 85分（含）-90分 | 中等偏上 |
| 2B级 | 80分（含）-85分 | 中等 |
| 2C级 | 75分（含）-80分 | 中等偏下 |
| 3A级 | 70分（含）-75分 | 偏下 |
| 3B级 | 65分（含）-70分 | 偏下 |
| 3C级 | 60分（含）-65分 | 偏下 |
| 4级 | 45分（含）-60分 | 落后 |
| 5级 | 45分以下 | 严重落后 |

总分100分，最小计分单位0.1分。**得分越高越好**（90分以上为1级）；级别数值越大（1级→5级）表示存在的问题越多、需要的监管关注程度越高。分级区间含下限、不含上限（如75分（含）至90分为2级）。

### 2.5 评价程序

方案制定 → 机构自评 → 评价实施（信息收集、初评、复评、审核四步骤，复评审核须集体研究/审议）→ 结果反馈 → 档案归集。

- 机构须真实、准确、完整提供数据材料；提交虚假材料的依法严肃处理。

### 2.6 评价结果运用（差异化监管措施）

| 评价结果 | 监管措施 |
|----------|----------|
| 1级、2A级 | **正向激励**：可适当降低消保相关现场检查频率、优先选择或推荐参加消保政策试点 |
| 2级 | 关注薄弱环节，窗口指导、现场通报、监管谈话 |
| 3级 | 2级措施 + 下发风险提示函、责令限期整改、责令内部问责，必要时公开披露不当行为 |
| 4级 | 3级措施 + 限制新业务开办、限制分支机构增设 |
| 5级 | 上述措施 + 依法责令暂停相关业务、追究直接负责高管责任、责令调整有关负责人及管理人员 |
| 3级及以下或排名持续下降 | 增加现场检查频率，可要求提高消保内部考核在综合绩效考评体系中的权重 |

- 消保评价结果按相应权重纳入机构整体监管评级（如消费金融公司、汽车金融公司消保权重15%，保险公司不低于5%）。

## 三、"五维检查思路"

所有检查项目按以下五个维度穿透式检查：

1. **制度健全性**：是否有制度、制度是否完善
2. **流程合规性**：流程是否符合制度规定
3. **执行有效性**：实际执行是否到位
4. **结果成效性**：执行效果是否达到预期
5. **整改闭环性**：发现问题是否整改到位

## 四、知识检索与降级规则

本 skill 不绑定任何特定账号、知识库 ID 或 MCP 服务，按下述顺序检索，任一层级无结果即降级到下一层：

1. **用户本轮提供的材料**：直接阅读本轮上传/引用的制度、自评表、清单、台账等文件。
2. **环境已连接的知识源**：若当前环境已连接知识库/资料库（如 ima 知识库、WorkBuddy 资料库 `knowledge_search`），检索"消保监管评价""投诉处理时限""适当性管理"等主题；未连接则跳过，不要反复尝试不存在的工具。
3. **外部检索**：使用 WebSearch/WebFetch 检索金融监管总局、中国政府网等官方发布，输出中标注 `[依据来源：外部检索，建议人工复核]`。
4. **内置基线**：以上均无结果时，以本文件第二部分与 `checklists.md` 为判定基线，输出标注 `[依据来源：内置参考基线，建议结合最新监管文件与机构内部制度复核]`。

**通用约束**：严禁编造监管条款；不确定的条款标注 `[待验证]`；需要机构内部数据而用户未提供时，输出数据需求清单而非假设数据。

## 五、金融消费者八项基本权利与检查归口

依据国办发〔2015〕81号，金融消费者享有八项基本权利。检查发现应归口到具体权利，便于与监管评价要素、消保审查口径对齐：

| 序号 | 基本权利 | 内涵要义 | 主要对应检查领域 | 典型违规表现 |
|------|----------|----------|------------------|--------------|
| 1 | 财产安全权 | 保障消费者资金与资产安全，不被非法侵害 | 操作与服务、个人信息保护 | 资金被违规划扣、账户被盗用、合作机构卷款、代客操作 |
| 2 | 知情权 | 以通俗语言真实、准确、完整披露产品与服务关键信息 | 操作与服务、金融教育 | 隐瞒风险、混淆产品类型、未明示年化利率与费率、披露不完整 |
| 3 | 自主选择权 | 自主选择产品、服务和渠道，不被强制搭售 | 操作与服务 | 强制捆绑搭售、默认勾选、以放贷为条件搭售、限制提前还款渠道 |
| 4 | 公平交易权 | 格式条款公平，收费合理，不得设置不公平不合理条件 | 操作与服务 | 不公平格式条款、乱收费、单方免责、加重消费者责任 |
| 5 | 依法求偿权 | 投诉、调解、仲裁、诉讼渠道畅通，处理及时有效 | 纠纷化解 | 投诉渠道不畅、超时未答复、处理结果不告知救济途径、推诿 |
| 6 | 受教育权 | 开展常态化金融知识教育，提升消费者金融素养 | 金融教育宣传 | 未开展集中教育、无常态化专区、内容形式化/误导性 |
| 7 | 受尊重权 | 尊重人格尊严与风俗习惯，特殊群体获得适配服务 | 消费者服务 | 歧视性服务、老年人/残障人士服务缺失、适老化改造不到位 |
| 8 | 信息安全权 | 个人信息收集、存储、使用、对外提供合法合规 | 个人信息保护 | 超范围收集、未告知同意、信息泄露、违规对外提供、员工违规查询 |

**使用方式**：撰写检查发现、整改通知、统计报表时，在"判定依据"之外增列"影响权利"，实现"权利—领域—要素"三层对应；季度/年度总结可按八项权利维度做问题分布分析，识别机构消保薄弱环节。
