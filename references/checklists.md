# 消保检查六大领域检查清单

> 执行检查任务时按本清单逐项检查。每项检查结果须记录：检查结果（达标/部分达标/不达标）、问题描述、问题来源（制度/流程/执行/结果）、证据索引、严重程度（重大/中等/一般）。
> 检查前先检索用户提供的监管评价自评表、内部检查制度和本机构检查标准；用户未提供时，以本清单及 `regulatory-basis.md` 为基线，并在输出中标注依据来源。
> 六大领域与监管评价七要素的对应关系已在各领域标题中标注；统计与报告请按七要素归口，避免与监管评价口径错位。

## 领域一：消保体制建设检查（对应监管要素：体制机制，权重≥10%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 董事会履职 | 是否将消保纳入公司治理、企业文化建设和经营发展战略；是否总体规划及指导；是否设立消保委员会并有效履职 | 查阅公司章程、董事会会议纪要、消保工作战略规划文件 |
| 监事会监督 | 是否对董事会、高级管理层消保履职情况进行监督 | 查阅监事会会议记录、监督意见书 |
| 高管层执行 | 是否统筹制定消保工作计划和任务，提供必要资源保障；是否指定高级管理人员分管消保 | 查阅高管层会议纪要、消保工作计划、预算审批文件、分管领导任命文件 |
| 制度建设 | 是否建立消保总括性制度和专项制度体系；是否建立消保审查、内部考核、内部审计等核心机制 | 查阅消保制度清单、制度文件全文、制度更新时间记录 |
| 部门设置 | 是否明确部门履行消保职责且职责完备；部门是否独立、专业、权威 | 查阅部门职责文件、人员编制表、部门设立通知 |
| 人员配备 | 消保人员是否充足；是否建立激励机制且不低于同类岗位平均水平 | 查阅人员信息表（学历、专业、专职情况）、薪酬制度 |
| 分支机构安排 | 各级分支机构是否明确消保职能部门/岗位安排 | 查阅分支机构消保岗位设置文件、人员信息 |
| 消保部门统筹 | 是否组织、协调、督促、指导其他部门及下级机构开展消保工作 | 查阅工作任务方案、协调会议纪要、工作部署文件 |

## 领域二：消保机制运行检查（对应监管要素：体制机制，权重≥10%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 消保审查机制 | 是否建立消保审查制度和机制；是否纳入风控体系；审查范围是否全覆盖（设计开发、定价管理、协议制定、营销宣传等环节）；审查意见是否具体明确、有可操作性；审查意见采纳情况；是否结合投诉、诉讼、舆情动态更新审查要点 | 查阅消保审查制度、审查台账、审查意见单（是否条目式、有依据和建议）、审查覆盖率统计、审查要点更新记录 |
| 内部考核机制 | 是否建立专门消保内部考核制度；考核对象、指标、方式、周期是否明确；考核指标是否合理（不得以投诉数量为唯一指标）；考核结果是否纳入综合绩效考评体系 | 查阅消保内部考核制度、考核结果通报、考核指标权重分配表、考核结果运用记录（与绩效、晋升、问责挂钩） |
| 内部审计机制 | 是否建立常态化、规范化的消保内部审计机制；是否纳入年度审计；是否以五年为一个周期实现全覆盖 | 查阅内部审计制度（含消保审计）、年度审计计划、审计报告、整改跟踪记录 |
| 信息披露机制 | 是否建立消保信息披露制度；是否通过年报/社会责任报告披露消保重大信息（含年度投诉数量、业务类别、地区分布） | 查阅信息披露制度、年报/社会责任报告消保披露部分 |
| 个人信息保护机制 | 是否建立个人信息保护制度；是否开展员工信息保护行为管理；是否建立信息系统管理要求；是否开展自查 | 查阅个人信息保护制度、员工行为管理制度（信息保护条款）、自查报告及整改记录 |
| 内部培训机制 | 是否建立消保内部培训机制；是否结合岗位类别开展针对性培训；是否覆盖新员工入职、管理人员任职 | 查阅培训制度、年度培训计划、培训签到表和课件、培训考核记录 |
| 金融教育宣传机制 | 是否开展常态化消费者教育；是否组织集中教育活动（"3·15"、9月宣传月）；是否建立公益性金融知识教育专区 | 查阅年度教育宣传计划、活动总结报告、教育专区照片/截图、活动数据统计 |
| 投诉处理机制 | 是否建立投诉处理工作制度、重大投诉应急管理机制、投诉处理考核评价机制和溯源整改机制；是否建立投诉处理信息化系统 | 查阅投诉管理办法、应急预案、系统截图、投诉台账、处理决定告知函、溯源整改记录 |

## 领域三：操作与服务检查（对应监管要素：营销行为管理≥25%、适当性管理≥10%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 营销宣传 | 是否建立营销宣传管理机制；是否存在欺诈或引人误解的宣传；是否使用禁用词（"保本""无风险""保收益"等）；风险提示是否充分、醒目；贷款产品是否明示年化利率；是否进行营销宣传活动监测；是否存在强制捆绑、强制搭售；电话/短信/网络推送营销是否提供拒收或退订选择 | 抽查营销宣传文本（至少5款产品，涵盖互联网产品、存款、信贷、保险、资管产品）；查看监测记录、问题整改记录 |
| 信息披露 | 是否售前、售中、售后全流程披露关键信息；是否通俗易懂；是否涵盖产品基本信息、风险、收费、合同主要条款 | 抽查3款产品（代销理财、代销保险、代销基金各1款）全部信息披露材料（风险揭示书、销售话术、产品说明书、合同文本）；检查信息查询平台 |
| 格式条款 | 是否以显著方式提请消费者注意重大利害关系内容；是否存在不公平、不合理规定 | 抽查3款销售规模最大产品的格式条款；检查显著标识（字体、字号、颜色、符号） |
| 适当性管理 | 是否建立适当性管理制度（依据、标准、方法、流程）；是否对投资型产品、可能导致本金损失的保险产品开展风险评级；保险产品分类分级是否符合监管要求；是否对消费者开展风险承受能力评估；评估是否审慎（是否存在代客评估、不当提示、先销售后评估、多次评估）；评估频次管控（单日不超2次、12个月累计不超8次）；评估结果有效期（原则上12个月）管理；是否提出明确匹配意见并留痕；是否对65周岁以上客户销售高风险产品履行特别注意事项义务；是否对无/限制民事行为能力人执行禁止或限制销售规则；产品销售资质分级与差别授权是否落地 | 抽查3款销售规模最大产品的风险评级材料；查看客户风险评估记录（问卷、得分、等级、有效期）；查看系统对评估频次的管控截图；抽查65周岁以上客户购买高风险产品的留痕与回访记录 |
| 销售行为（双录） | 是否建立销售专区"双录"管理机制；专区设置、标识、风险提示要求是否明确；录音录像资料保存是否合规；是否可人为更改、涂抹或删除；销售人员资质是否分级管理 | 查看"双录"管理制度；实地抽查3家网点（专区照片、标识、产品查询途径、咨询举报电话公示）；查看双录系统截图 |
| 合作机构管理 | 是否建立合作机构名单制管理（准入、运行、退出）；合作协议是否明确消保责任；是否进行过程管控 | 抽查合作机构合作协议（营销获客、担保增信、催收、代理销售等）；查看准入/退出标准、日常监督记录 |
| 服务质量与收费 | 是否在营业场所、网站主页醒目位置公示服务项目、内容、价格；新设收费项目或提价是否提前公示 | 实地查看营业场所、网站公示情况；检查服务价格公示文件 |

## 领域四：纠纷化解检查（对应监管要素：纠纷化解，权重≥25%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 投诉处理机制建设 | 是否建立投诉处理工作制度、重大投诉应急管理机制、考核评价机制和溯源整改机制；是否建立投诉处理信息化系统 | 查阅投诉管理办法、应急预案、系统截图 |
| 投诉渠道 | 是否在移动客户端或客服热线开通投诉渠道；是否在醒目位置公示投诉受理方式 | 查看官方网站、APP、营业场所的投诉渠道公示情况 |
| 投诉处理时效 | 是否在规定时限内（15日/30日/60日）答复投诉人；延期是否履行内部审批程序 | 抽查投诉工单，核查处理时间节点 |
| 投诉处理质量 | 处理结果是否完整告知（核实情况、依据理由、救济途径）；是否保留告知记录 | 抽查投诉处理决定告知函，检查内容完整性和告知记录 |
| 投诉统计分析 | 是否定期开展投诉统计分析；是否按时向监管部门报送；数据是否真实、完整 | 查阅投诉统计分析报告、监管报送记录；比对系统数据与报送数据 |
| 溯源整改 | 是否针对投诉突出问题查找薄弱环节和风险隐患；整改是否涵盖经营指标、产品开发、营销管理、业务流程 | 查阅溯源整改记录（TOP问题清单、整改措施、责任人、完成时限）；查看整改完成证明材料 |
| 纠纷多元化解 | 是否制定纠纷调解工作细则；是否建立应调响应、调解权限动态授予和异地授权、解纷方案快速审批机制 | 查阅纠纷调解工作细则、调解权限授权文件；查看调解案例记录 |

## 领域五：金融教育宣传检查（对应监管要素：金融教育，权重≥10%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 年度计划 | 是否制定年度金融教育宣传工作计划；是否包含目标、受众、内容和形式 | 查阅年度教育宣传工作计划 |
| 集中教育活动 | 是否组织"3·15"教育宣传周和9月金融教育宣传月活动；是否覆盖重点人群（老年人、学生、新市民等） | 查阅集中活动实施方案、活动总结报告、活动数据统计、照片/视频佐证材料 |
| 常态化教育 | 是否建立线上线下公益性金融知识教育专区；是否定期发布原创教育内容（图文、视频等） | 查看官网/APP教育专栏内容及更新频率；实地查看营业场所教育专区 |
| 教育内容质量 | 内容是否通俗易懂；是否使用"以案说险"等形式；是否对不同群体差异化教育 | 抽查教育宣传作品（至少3件），评估通俗性、针对性、创新性 |
| 经费保障 | 是否安排专项宣教经费；经费使用是否合理 | 查阅年度预算及经费使用台账 |

## 领域六：消费者服务与个人信息保护检查（对应监管要素：消费者服务≥5%、个人信息保护≥5%）

| 检查项目 | 检查要点 | 检查方法 |
|----------|----------|----------|
| 特殊群体服务 | 是否建立老年人、残障人士等特殊群体金融服务机制；是否为老年人保留传统服务方式（柜面人工、热线人工等）；自助终端或手机银行是否有适老化设计（界面简洁、字体放大、语音交互等）；是否建立残障人士服务规范 | 实地查看网点传统服务保留情况；体验适老化界面功能；查阅特殊群体服务制度 |
| 个人信息收集 | 收集个人信息是否告知目的、方式和范围；是否取得消费者同意；是否遵循"合法、正当、必要"原则 | 抽查合同文本、隐私政策、信息收集表单；检查授权内容完整性 |
| 个人信息存储与使用 | 存储是否安全；查阅和复制等操作是否规范；使用是否在授权范围内 | 查看数据存储安全措施；检查查阅审批记录 |
| 个人信息对外提供 | 对外提供是否取得消费者明确授权（单独同意）；合作方个人信息获取和使用是否受控；共享清单是否可核查 | 检查合作协议数据保护条款；查看对外提供审批记录、共享清单 |
| 敏感个人信息与影响评估 | 处理敏感个人信息（金融账户、生物识别、行踪轨迹等）是否取得单独同意并告知必要性与影响；是否开展个人信息保护影响评估（PIA）并留存报告 | 抽查敏感信息处理场景（人脸识别、声纹、信贷审批）；查看PIA报告及整改记录 |
| 委托处理与跨境 | 委托第三方处理是否签订数据保护协议、是否监督受托方；是否存在未经安全评估/备案的跨境提供 | 抽查外包与委外催收、云服务协议；查看跨境数据清单与合规手续 |
| 员工行为与权限管理 | 是否建立员工信息查询、导出、使用的审批与留痕；是否开展异常查询监测与问责；离职人员权限是否及时回收 | 抽查系统查询日志与审批单；查看异常查询预警记录、权限回收记录 |
| 营销名单来源合法性 | 电话/短信/APP推送营销名单来源是否合法、是否经消费者同意；是否提供拒收退订并有效执行 | 抽查营销名单台账及授权凭证；抽查退订执行记录 |

## 检查方法工具箱

| 方法 | 适用场景 | Agent 实现方式 |
|------|----------|----------------|
| 文档审阅法 | 核对制度文件、执行记录、数据报表是否符合标准 | 用户提供文档 → 按检查清单逐项比对 |
| 抽样检查法 | 对投诉工单、审查意见单、培训记录等按比例抽样 | 用户提供数据 → 按统计方法抽样分析 |
| 数据分析法 | 利用投诉、审查数据开展趋势分析和异常识别 | 数据分析工具/脚本 |
| 访谈提纲生成法 | 为现场访谈生成结构化提纲 | 基于检查清单生成访谈问题 |
| 检查记录表生成法 | 为现场检查生成标准化记录表 | 按检查项目清单生成空白记录表 |
| 人员访谈法 / 实地观察法 / 系统查验法 / 客户体验法 | 需人工现场执行 | 生成对应访谈提纲、观察清单、查验要点、体验测试脚本供人工使用 |
